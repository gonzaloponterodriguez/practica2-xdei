# AGENTS Rules

## Workflow
- Seguir GitHub Flow por cada issue.
- Crear issue remoto antes de codificar.
- Trabajar siempre en rama feature/* desde main.
- Cerrar issue mediante PR y merge a main.

## Mandatory Update
- Al finalizar cada issue, actualizar siempre:
  - PRD.md
  - architecture.md
  - data_model.md

## Data Loading
- Mantener el script import-data compatible con /bin/ash.
- Validar conteos minimos en Orion despues de cada cambio de modelo.
